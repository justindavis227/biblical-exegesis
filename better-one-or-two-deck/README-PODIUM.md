# Better One, or Two? — podium card

**Open:** double-click `index.html` (Chrome recommended). Press **F** for fullscreen. Works with wifi off.

**First thing after opening: press any key.** That arms the sound. Do it on the title frame, not in the phoropter.

| Key | Does |
|---|---|
| → · Space · PgDn · clicker forward | next |
| ← · PgUp · clicker back | back |
| **F** | fullscreen on/off |
| **B** or **.** | black screen (press again to return) |
| **M** | mute / unmute the phoropter clicks |
| **t** | countdown start / pause (frame 38) |
| **Shift+T** | countdown reset to 15:00 |
| Home / End | first / last frame |
| **?** | show the counter longer |

Clicking the timer on frame 38 also works: click = start/pause, double-click = reset.

**Jump to a frame:** add `#20` to the address bar (frame numbers, not labels). The phoropter run is frames 16–23; the live practice timer is 38.

**If the sound doesn't play:** you didn't press a key before the phoropter — press **?** once (it arms sound without moving a slide).

**Do not** edit `index.html` by hand. Content changes go through Claude Design → re-export → rebuild.
